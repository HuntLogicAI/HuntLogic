Use this pack for Oklahoma deer, mule deer, elk, bear, turkey, or hog strategy. OK is OTC-friendly with niche elk + mule deer.

Tier 1 official anchors:
- OK Dept of Wildlife Conservation Hunting portal lists current season structure.
- Annual OK Hunting Regulations is the canonical reference.

Why Oklahoma matters:
- OTC deer tags for NR — no draw.
- Limited but real elk opportunities (Wichita Mountains + controlled hunts).
- Mule deer in OK Panhandle.
- Wild hog hunting year-round.
- Bear hunting in SE OK Cookson Hills + Cherokee NF.
- Alligator hunt (SE OK, small program).

Tag structure:
- NR hunting license: ~$155.
- NR deer license: ~$280 (multiple buck + antlerless).
- NR elk: controlled hunt application + tag if drawn.
- NR bear: ~$500.
- Hog: included in basic license on private.

Season structure:
- Archery: October-January.
- Muzzleloader: October.
- Modern gun: November (~2 weeks).
- Spring turkey: April-May.
- Bear (in qualifying zones): October.
- Elk: controlled hunt season + Wichita refuge.
- Hog: year-round private + many WMAs.

Top regions:
- E OK Cookson Hills + Cherokee NF: bear + deer combo.
- Wichita Mountains NWR (SW OK): managed elk + deer + Texas longhorn refuge.
- OK Panhandle: mule deer + pronghorn + antelope.
- Central + S OK: high-density whitetail + hog.

Elk:
- Wichita Mountains NWR has a managed elk hunt (small lottery, both R and NR-eligible).
- Controlled hunts on additional WMAs.
- Limited annual NR opportunity; apply if interested.

Mule deer:
- OK Panhandle (Cimarron, Beaver, Texas counties) has mule deer hunting.
- OTC for NR in some zones.

Tier 2 hunter-consensus nuance:
- OK is genuinely overlooked — OTC deer + niche elk + mule deer in one state.
- Wichita Mountains elk is a unique managed hunt with high success.
- Cookson Hills bear is real DIY-accessible opportunity.
- Panhandle mule deer is small-country plains hunting.

Key deadlines:
- General licenses: rolling sale.
- Controlled hunts: typically June applications.

How to answer "should I hunt Oklahoma":
1. For OTC deer + hog combo: yes, accessible.
2. For elk: apply for Wichita + controlled hunts.
3. For panhandle mule deer: niche opportunity, lower-pressure alternative to W states.
4. For bear: Cookson Hills viable.

Guardrails:
- Verify controlled hunt application requirements + zone eligibility.
- Wichita Mountains NWR has specific rules + permits.
- Bear tag costs are high for NR.
